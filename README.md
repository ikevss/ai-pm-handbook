# 产品经理 AI Coding 工作手册

> 从传统 PM 到 AI 原生 PM 的转型指南

📖 **在线阅读：** https://ikevss.github.io/ai-pm-handbook/

> 💡 配套工具：[**AI 提示词手册**](https://ikevss.github.io/ai-pm-handbook/prompts/) — 把本手册的方法论沉淀成 74 条精选提示词，按场景分 10 类，点击卡片即可复制使用。

## 这是什么

这是一份面向产品经理的实操手册，系统梳理了 AI Coding 时代产品经理需要掌握的工作体系。

当产品经理从"描述需求让别人实现"变成"直接指挥 AI 实现"，原来的方法论、协作体系、思维范式和产出物全部需要重构。本手册帮你完成这个转变。

## 谁适合看

- 正在从传统 PM 向 AI 原生 PM 转型的产品经理
- 想直接用 AI 写代码实现产品想法的 PM
- 需要理解 AI 工程实践的产品负责人
- 带团队做 AI 产品的技术 PM

## 手册内容

### 8 个核心章节

**1. 协作体系**  
从线性瀑布到并行 AI 增强。梳理协作对象、协作结构、优先级模型的变化，以及多人 AI 协作时哪些产出物"回轻了"。

**2. 思维范式**  
6 个维度的范式变化：价值模型、边际成本、资产定义、壁垒来源、PM 核心能力、思考模型。每个维度按"旧范式→新范式"对照展开。

**3. 产出物体系**  
按四类梳理：彻底淘汰、全新新增、升级进化、回轻了（多人协作时仍需但重量大减）。最后给出三层分类和协作密度影响表。

**4. 变更管控**  
产出物按变更频率分三层管理（锚点层/进度层/执行层）。包含防偏移机制和 SDD/BDD/TDD/ADR 四个概念在新范式中的具体角色。

**5. 工作流**  
用图解方式对照旧范式和新范式的工作流，展示协作结构、信息流和产出方式的具体差异。

**6. 实操启动**  
最小化必备清单：5 步协作流程、6 个 PM 思维架构、价值公式、4 角色协作详解（产品/技术/AI/测试）。

**7. 标准模板**  
14 个完整模板，每个都包含格式和字段说明，可直接复制使用。按管控层级（锚点层/进度层/执行层）分类。

**8. 生产部署**  
CI/CD for Agent Workflows、版本管理、监控告警、回滚策略。

### 7 个进阶章节（对抗性评审后补全）

**Agent 记忆与状态管理**  
三层记忆模型：短期记忆（单 session）/长期记忆（锚点层）/工作记忆（进度层），与三层管控的映射。

**Eval 体系**  
5 维 Eval 矩阵（代码质量/UI 还原度/交互体验/安全性/一致性）+ 3 级 Eval 流水线（即时/屏级/里程碑）。

**Multi-Agent 编排**  
单 vs 多 Agent 决策表 + 3 种编排模式（流水线/并行/混合）+ 文件作为 Agent 间通信协议。

**上下文工程**  
3 层上下文预算（always-in/on-demand/RAG）+ 8 项优先级矩阵 + 压缩策略 + 4 模型跨模型适配表。

**模型选择与 Token 经济学**  
6 行模型选择矩阵（前沿/中等/轻量）+ 4 行模型路由规则 + 4 个 Token 策略（预算/缓存/Prompt 优化/增量生成）。

**Human-in-the-loop**  
5 个人工介入节点表 + 自动化 vs 必须人工的边界对比。

**生产部署与运维**  
CI/CD 流水线表 + 版本管理表 + 监控告警表 + 三级回滚策略。

## 如何使用

### 方式一：在线阅读（推荐）

访问 https://ikevss.github.io/ai-pm-handbook/

页面是单页应用，包含导航、交互动画、可折叠模板。适合快速查阅和系统学习。

### 方式二：本地阅读

```bash
# 克隆仓库
git clone https://github.com/ikevss/ai-pm-handbook.git

# 用浏览器打开
open ai-pm-handbook/index.html  # macOS
start ai-pm-handbook/index.html  # Windows
```

### 方式三：按需查阅

手册包含 14 个标准模板，可以直接复制使用：

1. Problem Framing（问题框定文档）
2. Design Brief（设计简报）
3. ADR（架构决策记录）
4. AGENTS.md（项目级 AI 指令文件）
5. Design Tokens JSON（机器可读设计规范）
6. Data Model Spec（数据模型定义）
7. BDD Scenarios（行为驱动开发场景）
8. Sitemap / IA（站点地图）
9. Flow Diagram（用户流程图）
10. Edge Case Matrix（异常态矩阵）
11. AC as Code（可执行验收标准）
12. Design QA Checklist（设计走查清单）
13. AC Trace Matrix（验收追溯矩阵）
14. System Prompt Library（提示词模板库）

这是一份**硬核实战手册**，不是营销落地页。

- ✅ 每个章节包含对照分析、操作指引和可直接复用的标准模板
- ✅ 覆盖从概念框架到生产部署的完整链路
